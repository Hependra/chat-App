Chat App using Node.js (Beginner Friendly)
This project is a beginner-friendly chat application built using Node.js, HTML, JavaScript, and CSS. It also includes database integration for storing user credentials and chat history.

Key Features:
User registration (sign up)

Login authentication with password hashing

Real-time messaging using Socket.IO

Chat history saved in the database

Simple and clean UI for beginners to understand and customize

This is a great starting point for anyone who wants to learn how to build a real-time chat app with Node.js and database support.

Note:
The project is still a work in progress, and a few improvements can be made. However, it's fully functional and serves as a solid base for learning and development.

Feel free to explore, modify, and use it in your own projects.
If you run into any issues or have suggestions, feel free to reach out!
